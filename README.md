# PerformanceLauncher v0.5.0

Launcher Minecraft Java para Android com foco em performance.

## Funcionalidades
- ✅ UI moderna dark theme
- ✅ Seletor de versão (1.7.10 a 1.21.1)
- ✅ Mod Browser (API Modrinth - busca e download real)
- ✅ Bolinha flutuante de configurações
- ✅ Presets de performance (Baixo/Médio/Alto/Ultra)
- ✅ Overlay FPS/RAM/Temperatura
- ✅ JVM args otimizados automáticos
- ✅ Download de mods/shaders/resourcepacks

## Presets
| Preset | Res | RAM | Dist | Uso |
|--------|-----|-----|------|-----|
| Baixo | 640x360 | 512MB | 4 | Celular fraco |
| Médio | 960x540 | 1GB | 8 | Celular médio |
| Alto | 1280x720 | 2GB | 12 | Celular bom |
| Ultra | 1600x900 | 3GB | 16 | Celular top |

## Build
Actions > Build APK > baixe o artifact ou Release.

## Instalação
1. Baixe o APK da Release
2. Instale (ative fontes desconhecidas)
3. Escolha o preset de performance
4. Baixe a versão do Minecraft
5. Instale mods pelo Mod Browser
6. Jogue
